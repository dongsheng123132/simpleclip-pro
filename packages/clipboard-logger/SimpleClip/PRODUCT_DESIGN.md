# SimpleClip 产品设计文档 (PRD)

## 1. 产品概述

SimpleClip 是一款 macOS 剪贴板管理工具，定位为「个人工作记忆库」，提供无限历史记录存储、智能分类、本地 AI 日报等功能。

### 1.1 核心定位
- **个人工作记忆库**：不只是剪贴板工具，而是工作内容的智能归档
- **隐私优先**：100% 本地处理，无云端上传
- **效率工具**：快速访问历史、智能搜索、一键粘贴

## 3. 功能设计

### 3.1 剪贴板监控

#### 3.1.1 监控机制
- **轮询间隔**：1 秒
- **变化检测**：通过 `NSPasteboard.general.changeCount` 判断
- **去重策略**：SHA256 内容哈希，重复内容不记录
- **数据类型**：文本、URL、图片（保存为 PNG）

#### 3.1.2 性能优化
- 限制主界面显示最多 200 条记录
- 图片生成缩略图缓存（NSCache）
- 数据库操作限制在主线程

### 3.2 主界面（Popover）

#### 3.2.1 布局结构
```
┌─────────────────────────────┐
│ SimpleClip   [管理][图片][固定][···] │  ← 顶部工具栏
├─────────────────────────────┤
│ 🔍 搜索历史记录...           │  ← 搜索栏
├─────────────────────────────┤
│ 📄 文本内容...          2分钟前 │  ← 历史列表
│ 🖼️ 图片                 5分钟前 │
│ 🔗 https://...         10分钟前 │
├─────────────────────────────┤
│ 12 项                    [清空] │  ← 底部工具栏
└─────────────────────────────┘
```

#### 3.2.2 交互设计
| 操作 | 响应 |
|------|------|
| 点击列表项 | 复制到剪贴板，如开启自动粘贴则模拟 Cmd+V |
| 右键列表项 | 弹出菜单：预览、复制、固定、删除 |
| Cmd+Shift+V | 全局快捷键，显示/隐藏窗口 |

### 3.3 固定窗口模式

#### 3.3.1 两种显示模式
| 模式 | 特点 | 适用场景 |
|------|------|----------|
| **透明模式** | 背景半透明，可看到后面内容 | 需要参照后面内容时使用 |
| **不透明模式** | 标准窗口背景 | 追求清晰度，可能更流畅 |

#### 3.3.2 窗口特性
- **置顶**：`window.level = .floating`
- **无边框**：`styleMask = [.borderless, .resizable]`
- **可拖拽**：`isMovableByWindowBackground = true`
- **跨桌面**：`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`
- **失焦不隐藏**：`hidesOnDeactivate = false`

#### 3.4.2 图片库
- 按日期分组（今天/昨天/本周/更早）
- 网格布局，自适应列数
- **保持比例显示**：图片使用 `.fit` 模式，保持原始比例
- 点击图片可放大查看
- **双指捏合缩放**：使用原生触控板手势

#### 3.4.3 Finder 集成

| 在 Finder 中显示 | 调用 `NSWorkspace.activateFileViewerSelecting` |

| 图片信息 | 显示像素尺寸（如 1702×1276）|

## 4. 交互细节

### 4.1 列表项交互（借鉴 Finder）

#### 4.1.1 悬停效果
- 鼠标悬停：背景变为淡蓝色（`Color.accentColor.opacity(0.08)`）
- 悬停时显示操作按钮：复制、固定
- **悬停自动预览**：鼠标停留在列表项上 500ms 后自动弹出预览气泡

#### 4.1.2 悬停自动预览
| 特性 | 说明 |
|------|------|
| 触发条件 | 鼠标悬停 500ms |
| 关闭条件 | 鼠标离开立即关闭 |
| 预览内容 | 文本/链接显示完整内容，图片显示缩略图 |
| 显示位置 | 图标左侧弹出气泡 |

#### 4.1.3 点击行为
| 位置 | 行为 |
|------|------|
| 整行（主窗口） | 复制内容到剪贴板 |
| 整行（管理窗口） | 选中该项，右侧显示详情 |

#### 4.1.4 右键菜单
```
┌─────────────────────┐
│ 复制到剪贴板        │
│ 固定 / 取消固定     │
├─────────────────────┤
│ 快速查看（图片）    │
│ 在浏览器打开（链接）│
├─────────────────────┤
│ 删除                │
└─────────────────────┘
```

### 4.2 图片预览

#### 4.2.1 图片比例处理
- **保持原始比例**：使用 `aspectRatio(contentMode: .fit)` 保持图片原始比例
- **背景填充**：使用灰色背景填充空白区域，避免视觉突兀
- **阴影效果**：轻微阴影提升层次感

#### 4.2.2 缩放操作
| 操作 | 功能 |
|------|------|
| 双指捏合 | 缩放图片（触控板原生手势）|
| Option+滚轮 | 缩放图片 |
| 拖拽 | 平移图片（缩放后）|
| 双击 | 还原到原始大小 |

#### 4.2.3 Finder 集成
- **在 Finder 中显示**：右键菜单可直接打开图片所在位置
- **图片信息显示**：显示像素尺寸（如 1702×1276）

## 5. 数据模型

### 5.1 ClipboardItem
```swift
@Model
class ClipboardItem {
    var id: UUID          // 唯一标识
    var content: String   // 文本内容或图片路径
    var type: ClipboardType // 类型: text/url/image
    var timestamp: Date   // 创建时间
    var isPinned: Bool    // 是否固定
    var contentHash: String // SHA256 哈希（去重用）
}
```

### 5.2 存储策略
- **文本/URL**：直接存储
- **图片**：保存到 `~/Library/Application Support/SimpleClip/Images/`
- **数据库**：SwiftData 自动管理，支持迁移

## 6. AI 功能

### 6.1 工作日报
- **生成时机**：每天指定时间（默认 22:00）
- **数据来源**：当天的文本和链接剪贴记录
- **AI 引擎**：
  - macOS 26+：Apple Intelligence（FoundationModels）
  - 低版本：NaturalLanguage 框架提取关键词

## 8. 性能考虑

### 8.1 优化策略
1. **列表限制**：最多显示 200 条，避免大数据量卡顿
2. **图片缓存**：缩略图使用 NSCache 缓存
3. **延迟加载**：LazyVStack 延迟加载列表项
4. **主线程保护**：SwiftData 操作限制在主线程

### 8.2 内存管理
- 图片缩略图限制尺寸（最大 200px）
- 定期清理缓存
- 大图查看时按需加载

---

## 9. 隐私与安全

- **100% 本地**：无网络请求，所有 AI 在设备上运行
- **沙盒机制**：启用 App Sandbox
- **数据加密**：依赖系统文件加密
- **权限最小化**：仅请求必要的辅助功能权限（用于自动粘贴）

---

## 10. 已知限制

1. **刘海屏 Mac**：状态栏空间有限，图标可能被隐藏
2. **辅助功能权限**：自动粘贴需要用户授权
3. **SwiftData 迁移**：模型变更时需要处理数据迁移
