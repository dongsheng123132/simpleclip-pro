Every AI conversation starts from zero. Your assistant doesn't know what you've been working on, what you care about, or what your day looks like. I built LifeClip to solve this — an open-source Personal Context System that auto-captures your digital behavior (clipboard, browser history, notes, AI chats) and generates AI-readable personal context. What makes v0.3 interesting: A two-stage insight pipeline: TF-IDF extraction produces structured JSON, then a pluggable AI provider (local TF-IDF, Apple Intelligence, or Claude API) generates human-readable insights. The key output is ~/.lifeclip/context.json — a file any AI tool can read to instantly understand your context. Think of it as .gitconfig for your identity, but for AI. 100% local processing. Zero network requests (unless you opt into the Claude API provider). Your data stays on your machine. Built with TypeScript (monorepo with npm workspaces) + Swift (macOS clipboard app). I built LifeClip — an open-source tool that generates personal context for AI assistants (100% local)
Title (above) / Body (below) — subs: r/ClaudeAI, r/LocalLLaMA, r/programming, r/commandline
I got tired of re-introducing myself every time I start a conversation with Claude or GPT. So I built LifeClip — it captures clipboard, browser history, Obsidian notes, and Claude Code sessions, then generates a `context.json` file that any AI can read. **How it works:** 1. `lifeclip collect` — pulls data from all sources into JSONL files 2. TF-IDF extracts topics and patterns (pure TypeScript, no LLM needed) 3. A pluggable AI provider generates human-readable insights (three options: local TF-IDF, Apple Intelligence via Swift helper, or Claude API) 4. `lifeclip context` outputs `~/.lifeclip/context.json` — feed this to any AI assistant Everything runs locally by default. The Claude API provider is opt-in. PII filter auto-redacts emails, phone numbers, credit cards, and API keys before processing. It's a TypeScript monorepo (npm workspaces) with a Swift macOS clipboard app. GPL-3.0. Limitations: macOS only for the clipboard logger (the CLI works anywhere with Node 18+). Browser history extraction currently supports Chrome and Safari. The TF-IDF provider works well for topic extraction but obviously can't match LLM-quality narratives. GitHub: https://github.com/dongsheng123132/lifeclip Happy to answer questions or hear feedback.

LifeClip captures your digital behavior (clipboard, browser history, Obsidian notes, Claude Code sessions) and generates a structured context.json that any AI tool can read.
