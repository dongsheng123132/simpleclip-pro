# SimpleClip - Personal Work Memory Bank

SimpleClip has evolved from a lightweight clipboard tool into a **Personal Work Memory Bank** with infinite storage and local AI capabilities.

## Key Features

### 1. Infinite Storage (SwiftData)
- **Zero Data Loss**: Replaced legacy file storage with Apple's **SwiftData** database.
- **Performance**: Capable of storing 100,000+ records without lag.
- **Infinite History**: No more 50-item limit. Records are kept indefinitely.
- **Smart Cleanup**: Only cleans up old images when disk space is critically low.

### 2. Memory Bank Manager
- **New Interface**: A dedicated Management Window (CMD+Shift+V -> Right Click -> "Open Manager").
- **Visual Gallery**: Browse image history in a grid view.
- **Search & Filter**: Instantly find code snippets, links, or screenshots.

### 3. Local AI Insights (Beta)
- **Privacy First**: All analysis happens on-device using macOS **Apple Intelligence** (or Natural Language framework as fallback).
- **Daily Summary**: Automatically generates a "Daily Work Summary" from your clipboard history every night.
- **Insight Panel**: (Coming Soon) Deep analysis of your coding patterns and problem-solving history.

## Usage

- **Activate**: `Cmd + Shift + V`
- **Quit**: Right-click the menu bar icon -> "Quit SimpleClip" or use the button in Settings.
- **Open Manager**: Right-click the menu bar icon -> "Open Manager".

## Privacy Policy
SimpleClip is 100% local. No data is ever uploaded to the cloud. Your memory stays on your machine.
